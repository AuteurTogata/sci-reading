# 不同论文类型的精读路线

先判型，再精读。不要把所有论文强塞进“实验论文模板”。

## A. 湿实验 / 材料 / 化学 / 工程实验

重点：
- 材料/样品制备
- 自变量与对照
- 条件（温度、时间、浓度、气氛等）
- 表征方法分别验证什么
- 重复与误差
- 结构—性能—机制证据链
- 机制是否有直接表征支持

## B. 数值模拟 / 多物理场 / CFD / FEA / DFT

重点：
- 控制方程/物理模型
- 几何与域定义
- 边界/初始条件
- 材料参数及来源
- 网格/时间步独立性
- 数值求解器与收敛准则
- 模型验证/实验对照
- 参数扫描与敏感性
- 指标的物理定义及归一化分母
- 模拟趋势是否被过度外推为真实系统因果

## C. 生物信息学 / 机器学习 / 数据驱动

重点：
- 数据集来源与划分
- 纳入/排除标准
- 预处理与泄漏风险
- 特征工程
- 训练/验证/测试设计
- 外部验证
- 基线模型
- 指标选择
- 类别不平衡
- 可解释性是否等同机制（通常不能）

## D. 临床 / 观察性研究

重点：
- 研究设计（RCT/队列/病例对照/横断面）
- 纳排标准
- 暴露/干预和结局定义
- 混杂因素
- 随访
- 样本量与缺失数据
- 统计模型
- 效应量与置信区间
- 因果措辞是否超越研究设计

## E. 方法学 / 新技术论文

重点：
- 新方法解决的具体瓶颈
- 与现有方法基线比较是否公平
- 验证任务是否覆盖真实使用场景
- 鲁棒性、灵敏度、特异性、误差、计算代价等适用指标
- 是否存在只挑有利数据集/任务的问题

## F. Review / Systematic Review / Meta-analysis

不要使用普通“自变量—因变量”框架。

### Narrative Review
重点：
- 主题范围
- 文献组织逻辑
- 主要观点与证据类型
- 领域争议
- 作者观点 vs 文献共识
- 未解决问题

### Systematic Review / Meta-analysis
额外重点：
- 检索数据库/日期/检索式
- 纳排标准
- PRISMA 流程
- 偏倚风险
- 异质性
- 合并效应与模型
- 敏感性分析
- 发表偏倚
- GRADE/证据等级（若使用）
