# 证据规则与反幻觉规范

## 1. 四层来源标签

### `[原文事实]`
论文直接报告的观测、实验、统计、模拟、表格或可明确读取的图表结果。

### `[作者解释]`
作者对结果给出的因果、机制或意义解释。即使作者写得很确定，也不能自动升级成“已证明事实”。

### `[Codex推断]`
基于公认学科原理或论文内部信息做出的合理解释，但本文没有直接验证。必须说明“这是推断”。

### `[待验证假说]`
有合理动机，但当前论文证据不足，必须用进一步实验、计算或独立数据验证。

## 2. 主张—证据强度

### 强
- 多个独立证据相互支持；或
- 直接测量与主张高度对应；或
- 合理对照 + 重复 + 统计/误差完整；或
- 模型经过与主张相关的独立验证。

### 中
- 有直接证据，但验证维度有限；或
- 对照/重复/统计部分不足；或
- 结论存在合理替代解释。

### 弱
- 主要来自相关性、单一 proxy、单个图或间接推断；或
- 关键条件/对照/验证缺失；或
- 机制结论明显超出直接证据。

“强/中/弱”是针对**某个 Claim 的证据支持程度**，不是对论文整体质量打分。

## 3. 常见逻辑越界

- correlation → causation：禁止自动升级。
- proxy → direct physical quantity：明确 proxy 的定义边界。
- simulation → experimental proof：模拟可支持机制/趋势，但不等于实验验证。
- one condition → universal conclusion：限制外推范围。
- statistically significant → practically important：统计显著不自动等于效应重要。
- no significant difference → same/equivalent：不能自动写成等效，除非做了等效/非劣检验。
- absence of evidence → evidence of absence：禁止。

## 4. 数值处理

- 文本、表格中的数值：可准确引用，并给位置。
- 图中标注的数值：可引用。
- 只能从曲线位置估计的数值：默认不要给精确值。
- 百分比变化：若论文未直接报告而需要计算，必须写明“根据原文数值计算”，并保留计算基准。
- 单位：保持原单位；如转换单位，说明转换。

## 5. 定位规范

优先写：`PDF p.7, Fig. 3b`。

可附：`Results, Section 3.2`。

如果 PDF 有印刷页码但与阅读器页码不同，至少保留 PDF 页码，避免学生无法回查。

## 6. Innovation 审查

不要把作者写的 “novel / first / unprecedented” 直接当事实。区分：
- 作者自称创新
- 从本文内部可以确认的新组合/新方法/新证据
- “首次”类主张需要外部文献检索才能独立核验；没有检索就写“作者声称首次，本文内部无法独立核验”。

## 7. 缺失信息

使用这些标准措辞：
- `原文未明确报告`
- `当前 PDF 中未发现`
- `需要 Supplementary Information 才能核验`
- `图像分辨率不足，无法可靠读取精确数值`
- `需要外部数据库核验`
